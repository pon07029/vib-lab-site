# Publications Compact Typography Design

## Goal

Reduce the oversized typography in the Publications archive and create a compact, readable academic-record hierarchy.

## Typography

- Reduce the page heading from the current display scale to `48–78px`.
- Keep supporting copy at `16px` with comfortable line height.
- Keep toolbar labels, buttons, counts, status text, and list metadata at `9–10px` in the mono font.
- Reduce publication titles in the left list to `15–19px`.
- Reduce the selected publication title to `30–44px`.
- Reduce the contribution quote to `17px` and use a relaxed line height.
- Set author and journal values to `13–14px`; keep their labels at `9px`.
- Keep the external-record link at `10px`.

## Layout Effects

Tighten the toolbar and publication-row heights slightly to match the smaller type. Preserve the existing two-column archive layout, colors, selection behavior, filters, and large-desktop single-viewport treatment.

## Responsive Behavior

Retain the existing stacked mobile layout. The smaller type applies consistently without changing interaction or content.

## Verification

Review the stylesheet diff only. The user requested no automated tests.
