# Cobalt Blue Accent Design

## Goal

Replace the existing orange accent with cobalt blue while preserving every layout, neutral surface, and interaction.

## Change

- Update the shared `--signal` token from `#FF9100` to cobalt blue `#3D63D8`.
- Leave the off-white, charcoal, black, and gray tokens unchanged.
- All current accent uses, including selection state, active indicators, arrows, and highlights, inherit the new blue automatically.

## Verification

Confirm the shared token is the only source change. No automated tests are required for this visual-token update.
